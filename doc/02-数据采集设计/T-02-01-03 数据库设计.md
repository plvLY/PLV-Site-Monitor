# T-02-01-03 数据库设计

**版本：** V1.2
**状态：** 最终验收版

## 1. 设计原则

- PostgreSQL。
- Drizzle ORM。
- 多站点隔离。
- 一个站点支持多个域名。
- 原始事件独立保存。
- 事件唯一性约束。
- 支持 PV、UV、IP 和来源统计。
- UV 使用 `visitor_id` 识别匿名访客。
- Session 使用 `session_id` 识别会话。
- 原始 IP 最长保留 30 天。
- 不使用 `ip_hash`，不实现 HMAC IP Hash。

## 2. ER 关系

```
erDiagram
    sites ||--o{ site_domains : owns
    sites ||--o{ page_events : collects

    sites {
        uuid id PK
        varchar name
        varchar status
        varchar timezone
        timestamp created_at
    }

    site_domains {
        uuid id PK
        uuid site_id FK
        varchar domain
        boolean is_primary
        timestamp created_at
    }

    page_events {
        bigint id PK
        uuid site_id FK
        uuid event_id
        uuid visitor_id
        uuid session_id
        varchar event_type
        text page_url
        text page_path
        inet ip_address
        varchar country_code
        varchar city
        timestamp occurred_at
        timestamp received_at
    }
```

## 3. sites 站点表

| 字段       | 类型         | 说明              |
| ---------- | ------------ | ----------------- |
| id         | uuid         | 主键              |
| name       | varchar(100) | 站点名称          |
| status     | varchar(20)  | active / disabled |
| timezone   | varchar(64)  | 统计时区          |
| created_at | timestamptz  | 创建时间          |
| updated_at | timestamptz  | 更新时间          |

Site ID 是公开标识，不承担身份认证功能。

## 4. site_domains 域名表

| 字段       | 类型         | 说明       |
| ---------- | ------------ | ---------- |
| id         | uuid         | 主键       |
| site_id    | uuid         | 关联站点   |
| domain     | varchar(255) | 规范化域名 |
| is_primary | boolean      | 是否主域名 |
| created_at | timestamptz  | 创建时间   |

约束：

- 一个站点允许多个域名。
- 一个域名默认只能归属一个站点。
- 域名统一小写。
- 去除末尾点和端口。
- 不保存协议、路径和查询参数。
- 不默认允许任意通配符域名。

## 5. page_events 访问事件表

| 字段          | 类型         | 说明                          |
| ------------- | ------------ | ----------------------------- |
| id            | bigserial    | 主键                          |
| site_id       | uuid         | 站点 ID                       |
| event_id      | uuid         | 事件唯一 ID                   |
| event_type    | varchar(30)  | page_view                     |
| visitor_id    | uuid         | 匿名访客 ID，用于 UV 统计     |
| session_id    | uuid         | 会话 ID，用于 Session 统计    |
| page_url      | text         | 清理后的 URL                  |
| page_path     | text         | 页面路径                      |
| page_title    | varchar(500) | 页面标题                      |
| referrer      | text         | 来源 URL                      |
| referrer_host | varchar(255) | 来源域名                      |
| utm_source    | varchar(255) | 来源                          |
| utm_medium    | varchar(255) | 媒介                          |
| utm_campaign  | varchar(255) | 活动                          |
| utm_term      | varchar(255) | 关键词                        |
| utm_content   | varchar(255) | 内容                          |
| user_agent    | text         | 服务端读取                    |
| device_type   | varchar(30)  | 设备类型                      |
| browser       | varchar(100) | 浏览器                        |
| os            | varchar(100) | 操作系统                      |
| ip_address    | inet         | 原始 IP，可空，最长保留 30 天 |
| country_code  | varchar(2)   | 国家代码                      |
| region        | varchar(100) | 行政区                        |
| city          | varchar(100) | 城市                          |
| occurred_at   | timestamptz  | 客户端时间                    |
| received_at   | timestamptz  | 服务端时间                    |

统计标识说明：

- PV：根据访问事件数量统计。
- UV：根据统计周期内不同的 `visitor_id` 数量统计。
- Session：根据统计周期内不同的 `session_id` 数量统计。
- IP：基于保留期内的 `ip_address` 进行统计，不作为 UV 或 Session 的识别依据。

隐私设计：

- 不保存 `ip_hash` 字段。
- 不实现 IP HMAC Hash。
- 不额外维护 IP Hash 密钥。
- 原始 IP 到期后置空，事件记录及其他统计字段继续保留。

## 6. 事件去重

唯一约束：

```
UNIQUE (site_id, event_id)
```

确保同一站点同一个事件不会重复保存。

重复事件返回 duplicate 状态，不重复写入。

## 7. 索引

```
CREATE INDEX idx_page_events_site_received
ON page_events (site_id, received_at DESC);

CREATE INDEX idx_page_events_site_visitor
ON page_events (site_id, visitor_id, received_at);

CREATE INDEX idx_page_events_site_session
ON page_events (site_id, session_id, received_at);

CREATE INDEX idx_page_events_site_path
ON page_events (site_id, page_path);
```

唯一约束已经覆盖 `(site_id, event_id)`，不重复创建索引。

## 8. IP 保留策略

原始 IP 最长保留 30 天。

保留策略：

- 使用服务端 `received_at` 判断 IP 保留期限。
- 不使用客户端 `occurred_at` 作为清理依据。
- 超过 30 天的原始 IP 置为 `NULL`。
- 不删除历史事件记录。
- 不影响 `visitor_id`、`session_id` 和其他事件字段。
- 清理任务可重复执行，不应重复影响已经清理的数据。

定时清理 SQL：

```
UPDATE page_events
SET ip_address = NULL
WHERE received_at < NOW() - INTERVAL '30 days'
  AND ip_address IS NOT NULL;
```

清理规则：

- 严格清理早于 30 天的记录。
- 恰好处于 30 天边界的记录暂不清理。
- 仅清空 `ip_address`。
- 保留事件记录和其他统计数据。

清理任务由 Netlify Scheduled Function 定期执行。

## 9. 统计时间

主要统计时间使用 `received_at`。

`occurred_at` 仅用于辅助判断客户端事件时间。

统一使用 timestamptz。

## 11. 设计约束

- 不采集不必要的个人信息。
- 不保存敏感 URL 参数。
- 不信任客户端 IP 和地域。
- 不把 visitor_id 视为真实自然人身份。
- 不使用 IP Hash 作为访客识别手段。
- 不实现 HMAC IP Hash。
- 不无限期保存原始 IP。
- 原始 IP 最长保留 30 天。
- IP 清理仅清空 IP 字段，不删除历史事件。
- 后续按实际数据规模评估分区和归档。
