# T-02-01-01 数据采集需求分析

**项目：** PLV Site Monitor
**版本：** V1.1
**状态：** 最终验收版
**阶段：** T-02-01

## 1. 项目目标

建设轻量级、多站点的网站访问统计数据采集系统。

网站只需要嵌入一段 JavaScript Tracker，即可将访问事件发送到 PLV Site Monitor，统一保存到 PostgreSQL 数据库。

支持：

- Netlify
- Vercel
- GitHub Pages
- 自定义域名
- 其他支持 JavaScript 的网站

## 2. 核心采集流程

```
flowchart TD
    A[用户访问目标网站] --> B[加载 Tracker.js]
    B --> C[读取或生成 visitor_id]
    C --> D[读取或生成 session_id]
    D --> E[采集页面及路由信息]
    E --> F[POST /api/collect]
    F --> G[Netlify Function]
    G --> H[站点及域名校验]
    H --> I[请求参数校验和限流]
    I --> J[服务端获取 IP 和地域]
    J --> K[事件去重]
    K --> L[(PostgreSQL)]
```

## 3. 站点接入需求

一个站点对应一个独立 Site ID。

一个站点支持绑定多个域名。

示例：

```
Site ID: site-001

绑定域名：
- plvstudio.netlify.app
- plvstudio.com
- www.plvstudio.com
```

| FR-004 | 域名增加、修改和解绑  | P0     |

## 5. 访客和会话识别

### 5.1 visitor_id

使用网站第一方 localStorage。

存储键：

```
plv_analytics_visitor_id
```

规则：

1. 首次访问生成 UUID。
2. 保存至当前网站 localStorage。
3. 后续访问复用。
4. 不同域名默认独立访客标识。
5. 用户清理浏览器存储后重新生成。

该标识代表匿名浏览器，不代表真实自然人。

### 5.2 session_id

使用 sessionStorage。

存储键：

```
plv_analytics_session_id
```

规则：

1. 当前标签页首次访问时生成 UUID。
2. 同一标签页内持续复用。
3. 不同标签页可以有不同 session_id。
4. 标签页会话结束后不再保留。
5. 后续统计阶段可根据活动时间重新定义分析口径。

## 6. SPA 采集需求

首版支持常见单页应用路由变化自动采集。

支持：

- Vue Router
- React Router
- History API
- hash 路由

触发规则：

| 场景                  | 是否上报   |
| --------------------- | ---------- |
| 首次页面加载          | 是         |
| pushState 路由变化    | 是         |
| replaceState 路由变化 | 是         |
| 浏览器后退/前进       | 是         |
| hash 路由变化         | 是         |
| 同一路径重复通知      | 否         |
| 页面标题单独变化      | 不单独上报 |

Tracker 必须对路由变化去重，避免多个事件监听器导致重复 PV。

## 7. 隐私要求

- 不采集姓名、邮箱、手机号等直接身份信息。
- 不采集表单内容、密码及支付信息。
- URL 必须过滤敏感参数。
- 不保存 URL fragment。
- 不使用第三方 Cookie。
- 原始 IP 最长保留 30 天。
- 超过 30 天必须删除原始 IP 或执行不可逆匿名化。
- IP Hash 仍属于需要保护的数据，不得将其直接视为匿名数据。

## 8. MVP 功能边界

必须实现：

1. 多站点接入。
2. 多域名绑定。
3. Tracker.js。
4. 页面访问采集。
5. visitor_id。
6. session_id。
7. SPA 自动路由采集。
8. 服务端 IP 和地域获取。
9. PostgreSQL 事件保存。
10. 事件去重。
11. URL 敏感信息过滤。
12. 基础限流和域名校验。

暂不实现：

- 热力图。
- 用户行为录制。
- 鼠标轨迹。
- 漏斗分析。
- 用户画像。
- 自定义事件。
- A/B 测试。
